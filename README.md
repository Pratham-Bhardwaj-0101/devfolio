# FrameFound

FrameFound is a visual-discovery interface where people will be able to search a topic and browse matching images.
I chose a warm cream background with forest-green accents to give the app an editorial, nature-inspired feel instead of a generic tech-dashboard look.
The category chips offer quick inspiration for people who are unsure what to search for.
A clear empty state and a result-count placeholder explain what the page is for before any results exist.
